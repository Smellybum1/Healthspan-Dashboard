# Milestone 2 — Persistent Data Backbone and Primary-Source Ingestion

**Status:** Complete  
**Branch:** `milestone-2/persistent-data-backbone`  
**Deliverable commit:** `4a39a1c`  
**Authorised by:** ChatGPT Pro project manager (23 July 2026)

## Goal

Durable Windows-first local SQLite + Drizzle persistence, primary-source connectors (PubMed → ClinicalTrials.gov → Crossref DOI enrichment → TGA RSS), ingestion/versioning/change detection, and strict Live/Demo separation via `dataOrigin` / `dataMode`.

## Non-goals (M2)

AI extraction, evidence scoring, creator monitoring, X/YouTube, ARTG, auth, D1/R2/Sites, personal health data.

## Key paths

| Platform | Default DB                                                                           |
| -------- | ------------------------------------------------------------------------------------ |
| Windows  | `%LOCALAPPDATA%\Healthspan Dashboard\healthspan-dashboard.sqlite3`                   |
| macOS    | `~/Library/Application Support/Healthspan Dashboard/healthspan-dashboard.sqlite3`    |
| Linux    | `${XDG_DATA_HOME:-~/.local/share}/healthspan-dashboard/healthspan-dashboard.sqlite3` |

Raw snapshots: `<dataDir>/raw/sha256/<aa>/<hash>.<ext>.gz`
