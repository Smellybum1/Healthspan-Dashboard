# Milestone 1 — Product foundation and high-fidelity prototype

## Objective

Local end-to-end prototype with seeded data, design system, routes, Signal Radar, dossiers, watchlists, methodology, docs, and tests. No live external APIs.

## Exit gate

The product can be explored with convincing seeded data, architecture is documented, and `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm test:e2e`, and `pnpm build` pass.
