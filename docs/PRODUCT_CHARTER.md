# Healthspan Dashboard — Product Charter

**Working name:** Healthspan Dashboard  
**Tagline:** Longevity intelligence, evidence first.  
**Primary user:** Tom  
**Initial deployment:** Local computer  
**Later deployment target:** ChatGPT Sites (subject to runtime compatibility review)

## Product thesis

Healthspan Dashboard is an evidence-first intelligence system for longevity and healthspan research. It answers:

1. What changed since the last visit?
2. What is genuinely new rather than merely trending?
3. How strong is the evidence, especially in humans?
4. What safety, regulatory, conflict-of-interest, or translation caveats apply?
5. Which papers, trials, interventions, creators, and organisations deserve continued attention?

It is not a medical-advice engine, dosage guide, marketplace, peptide sourcing tool, or personal lifespan predictor.

## Product split

- **Healthspan Dashboard (now):** hostable research-intelligence dashboard with public-source information, watchlists, preferences, and evidence assessments.
- **My Healthspan (later, optional):** separate local encrypted personal module. Must not share the public dashboard database.

## Milestone 1 status

Delivered as a local prototype with seeded demo data, full navigation, Signal Radar, dossiers, watchlists, methodology, API boundary, and automated tests. No live external APIs.
