# Data model

Canonical Zod schemas live in `packages/core/src/schemas.ts` and taxonomies in `packages/core/src/taxonomies.ts`.

## Core entities

- Source, SourceRecord
- ContentItem
- Paper, Trial, Intervention, Peptide
- Creator, Claim
- EvidenceAssessment
- RegulatoryEvent, Organisation
- Watchlist, ChangeEvent, ReviewTask
- SignalRadarPoint, DashboardPayload, SeedBundle

## Independent evidence dimensions

- Evidence maturity
- Confidence (score + rationale list)
- Translation gaps
- Attention score + rationale
- Safety notes
- Regulatory statuses by jurisdiction

## Seed data

Generated by `scripts/generate-seed.mjs` into `packages/core/src/seed/bundle.ts`.

- 60+ coherent content records (papers, trials, interventions, peptides, creators, claims, regulatory events, organisations, watchlists, change events, review tasks)
- All records set `demo: true`
- UI shows a persistent demo snapshot notice

## Persistence (M1)

In-memory seed repository via `@healthspan/db`. SQLite + Drizzle planned for Milestone 2.
