# Shared project language

| Term                 | Meaning                                                       |
| -------------------- | ------------------------------------------------------------- |
| Healthspan Dashboard | Public/research intelligence product (this repo)              |
| My Healthspan        | Future separate personal encrypted companion                  |
| Evidence maturity    | Ladder from anecdotal → regulatory/guideline-supported        |
| Attention            | Discussion/mention momentum, independent of evidence          |
| Signal Radar         | Scatter of evidence maturity (X) vs attention (Y)             |
| Translation gap      | Explicit leap (e.g., animal→human) that must stay labelled    |
| Demo snapshot        | Fictionalised Milestone 1 seed data, not live facts           |
| Provenance           | Source IDs / source-record IDs backing an assessment          |
| Needs Review         | Low-confidence matches/summaries requiring human confirmation |
